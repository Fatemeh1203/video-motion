# راهنمای اسکیل‌های نصب‌شده

**کارایی هر اسکیل و نحوهٔ فراخوانی آن در Claude Code**

فاطمه شمس · آبان ۱۴۰۵

این راهنما همهٔ ۵۲ اسکیلی را که برای ساخت ویدیو موشن، ادیت ویدیو و محتوای اینستاگرام فارسی نصب شده، معرفی می‌کند. برای هر اسکیل نوشته شده که چه کاری می‌کند و چطور صدایش بزنی.

نسخهٔ کامل اسکیل‌ها در ریپوی github.com/Fatemeh1203/Claude-Custom-Skills است.

## چطور یک اسکیل را صدا بزنم؟

1. **با اسم اسکیل:** اول پیام یک خط مورب (/) و بعد اسم اسکیل را بنویس، و در ادامه درخواستت را به فارسی بگو.  
   مثال: `/ig-reel` یه ریلز درباره‌ی ساخت جزوه با هوش مصنوعی

2. **بدون اسم، فقط با درخواست:** لازم نیست اسم‌ها را حفظ کنی. اگر درخواستت به یک اسکیل بخورد، Claude خودش آن را باز می‌کند.  
   مثال: یه ویدیو موشن ۳۰ ثانیه‌ای برای معرفی کامیونیتی بساز

3. **همراه با فایل:** برای ادیت ویدیو یا تحلیل آمار، فایل را بفرست و در همان پیام بگو چه می‌خواهی.  
   مثال: `/video-edit` این ویدیو رو ادیت کن و زیرنویس فارسی بذار


**نکته‌ها**

- اسکیل‌هایی که در جدول‌ها با «خودکار» مشخص شده‌اند فنی‌اند و اسکیل‌های دیگر خودشان صدایشان می‌زنند. معمولاً لازم نیست مستقیم سراغشان بروی.
- برای هر کار ویدیویی، شروع از `/video-studio` (ساخت) یا `/video-edit` (ادیت ویدیوی ضبط‌شده) کافی است. بقیه را خودش انتخاب می‌کند.
- اسکیل‌های اینستاگرام لحن و عددهای واقعی تو را از فایل voice.md می‌خوانند و هیچ عددی از خودشان نمی‌سازند. یک بار پرش کن.
- برای دیدن فهرست اسکیل‌ها در هر لحظه بنویس: «لیست اسکیل‌های نصبی رو بده».


## ۱. اسکیل‌های اختصاصی من

این‌ها برای کار خودم نوشته یا تنظیم شده‌اند و برندم (فارسی راست‌چین، فونت وزیرمتن، رنگ‌های سایت، QR و لینک گروه تلگرام) را خودکار اعمال می‌کنند.

| اسکیل | کارایی | نمونهٔ فراخوانی |
|---|---|---|
| `video-studio` | درِ ورود همهٔ ویدیوها: موتور مناسب را انتخاب می‌کند، برند را اعمال می‌کند، گوینده و موزیک می‌گذارد و MP4 حداکثر ۲ دقیقه تحویل می‌دهد. | `/video-studio` یه تیزر ۳۰ ثانیه‌ای برای کامیونیتی بساز |
| `video-edit` | ادیت ویدیوی ضبط‌شدهٔ خودم: متن‌کردن صدا، گرفتن مکث و «اِم» و تکرار، گرافیک و زیرنویس، بازبینی. خروجی MP4 یا پروژهٔ Premiere. | `/video-edit` مکث‌ها رو بگیر و خروجی برای پریمیر بده |
| `human-tone` | متن را از حالت ماشینی درمی‌آورد: کلیشه‌ها، خط تیرهٔ زیاد، جمله‌های سه‌تایی و تعریف‌های اغراق‌آمیز را برمی‌دارد. فارسی و انگلیسی. | `/human-tone` این متن رو انسانی‌تر کن |
| `concise-responses` | جواب‌ها را کوتاه، مستقیم و بدون حاشیه نگه می‌دارد. | `/concise-responses` خلاصه بگو |

## ۲. اینستاگرام فارسی

سیزده اسکیل برای ادارهٔ پیج اینستاگرام آموزشی. به حساب اینستاگرام وصل نمی‌شوند و هیچ چیزی بدون تأیید تو پست نمی‌شود.

| اسکیل | کارایی | نمونهٔ فراخوانی |
|---|---|---|
| `ig-reel` | از ایدهٔ خام تا ریلز: سه هوک امتیازدار، اسکریپت گفتاری، متن روی صفحه و جدول زمان‌بندی. | `/ig-reel` یه ریلز درباره‌ی پرامپت‌نویسی برای معلم‌ها |
| `ig-caption` | کپشن با بررسی ۱۲۵ کاراکتر اول، یک درخواست مشخص و حداکثر پنج هشتگ. | `/ig-caption` برای این ریلز کپشن بنویس |
| `ig-carousel` | کاروسل: جلد، متن اسلاید به اسلاید و فایل‌های ۱۰۸۰×۱۳۵۰ راست‌چین. | `/ig-carousel` اینو کاروسل ۷ اسلایدی کن |
| `ig-story` | استوری‌های روز، فریم به فریم، با جای استیکرها. | `/ig-story` امروز چی استوری کنم؟ |
| `ig-plan` | برنامهٔ هفته: چه پستی، با چه قالبی، چه روزی. | `/ig-plan` هفته‌مو برنامه‌ریزی کن |
| `ig-profile` | نمرهٔ پروفایل از ۱۰۰ و بازنویسی بیو، هایلایت‌ها و پست‌های پین‌شده. | `/ig-profile` به پیجم نمره بده (با اسکرین‌شات پروفایل) |
| `ig-human` | پاک کردن کلیشه‌های متن ماشینی فارسی، درست کردن نیم‌فاصله و «ی/ک» عربی، و نمرهٔ انسانی بودن. بقیهٔ اسکیل‌های ig به این وابسته‌اند. | `/ig-human` این کپشن ماشینی به نظر می‌رسه؟ |
| `ig-comment` | کامنت زیر پست دیگران که شبیه آدم باشد، نه ربات. | `/ig-comment` زیر این پست چی بنویسم؟ |
| `ig-reply` | دسته‌بندی کامنت‌های پست خودت و پیش‌نویس جواب برای آن‌هایی که ارزش جواب دارند. | `/ig-reply` جواب این کامنت‌ها رو بنویس |
| `ig-dm` | دایرکت: تحویل کلمهٔ کامنت، پیام اول، پیشنهاد همکاری و پیگیری. | `/ig-dm` یه پیام همکاری برای این مدرسه بنویس |
| `ig-repurpose` | تبدیل یک ویدیو، کلاس یا کارگاه بلند به یک هفته ریلز و کاروسل. | `/ig-repurpose` از این کلاس ضبط‌شده ریلز دربیار |
| `ig-viral` | تحلیل رقبا: ریلزهایی که چند برابر معمول پیجشان دیده شده‌اند و فرمول هوکشان. | `/ig-viral` این پیج رو تحلیل کن |
| `ig-audit` | تحلیل آمار پست‌های قبلی: کدام جواب داد، چرا، و چه چیزی را دیگر نسازی. | `/ig-audit` آمارمو بخون (با آمار Insights) |

## ۳. گردش‌کارهای ساخت ویدیو با HyperFrames

HyperFrames ویدیو را از HTML می‌سازد و برای متن فارسی و موشن گرافیک بهترین گزینه است. هر کدام از این‌ها برای یک نوع ویدیوست.

| اسکیل | کارایی | نمونهٔ فراخوانی |
|---|---|---|
| `hyperframes` | درِ ورود اصلی: درخواست را می‌خواند و به گردش‌کار مناسب می‌فرستد. برای بررسی و رندر پروژهٔ موجود هم همین. | `/hyperframes` این پروژه رو رندر کن |
| `general-video` | ویدیوی بلند و چندصحنه‌ای، تیزر برند، مونتاژ، کارت عنوان. | `/general-video` یه ویدیوی ۱ دقیقه‌ای چندصحنه‌ای بساز |
| `motion-graphics` | موشن کوتاه زیر ۳۰ ثانیه: تایپوگرافی متحرک، عدد شمار، لوگو، نمودار، زیرنویس اسم. | `/motion-graphics` یه تایپوگرافی متحرک ۱۰ ثانیه‌ای |
| `faceless-explainer` | ویدیوی توضیحی بدون چهره از روی یک متن، مقاله یا موضوع. | `/faceless-explainer` از این مقاله ویدیوی توضیحی بساز |
| `product-launch-video` | ویدیوی معرفی محصول یا سایت از روی آدرس سایت یا متن. | `/product-launch-video` برای سایتم ویدیوی معرفی بساز |
| `music-to-video` | ویدیوی هماهنگ با ضرب موزیک: لیریک‌ویدیو، اسلایدشو، تیزر ریتمیک. | `/music-to-video` با این آهنگ یه اسلایدشو بساز |
| `talking-head-recut` | کارت‌های گرافیکی روی ویدیوی صحبت‌کردن: عنوان، اسم، عدد، نقل‌قول. | `/talking-head-recut` روی این ویدیو گرافیک بذار |
| `embedded-captions` | زیرنویس روی ویدیوی صحبت‌کردن، ساده یا سینمایی (حتی پشت سر گوینده). | `/embedded-captions` به این ویدیو زیرنویس بده |
| `slideshow` | ارائه و اسلاید تعاملی با یادداشت ارائه‌دهنده (خروجی صفحهٔ وب، نه MP4). | `/slideshow` برای کارگاهم ارائه بساز |
| `pr-to-video` | ویدیوی توضیح تغییرات کد از روی یک Pull Request گیت‌هاب. | `/pr-to-video` از این PR ویدیو بساز |
| `figma` | آوردن طرح، لوگو یا رنگ‌های فیگما داخل ویدیو. | `/figma` این طرح فیگما رو متحرک کن (با لینک فیگما) |
| `remotion-to-hyperframes` | تبدیل پروژهٔ Remotion به HyperFrames. | `/remotion-to-hyperframes` این پروژه رو تبدیل کن |

## ۴. اسکیل‌های فنی HyperFrames

این‌ها را گردش‌کارها خودشان صدا می‌زنند (خودکار). فقط وقتی کار خیلی مشخصی داری مستقیم صدایشان بزن.

| اسکیل | کارایی | نمونهٔ فراخوانی |
|---|---|---|
| `hyperframes-core` | قواعد ساخت یک ترکیب قابل‌رندر: زمان‌بندی، لایه‌ها، صحنه‌ها. | خودکار |
| `hyperframes-cli` | دستورهای خط فرمان: init، check، snapshot، render و رفع خطای رندر. | `/hyperframes-cli` چرا رندر خطا می‌ده؟ |
| `hyperframes-animation` | قواعد حرکت، الگوی صحنه‌ها، ترنزیشن‌ها و افکت‌های متن. | خودکار |
| `hyperframes-audio` | میکس صدا: فید، پایین آوردن موزیک زیر گوینده، اکولایزر و افکت‌ها. | `/hyperframes-audio` موزیک رو زیر صدام کم کن |
| `hyperframes-keyframes` | زوم، پانچ‌این، حرکت دوربین و کن‌برنز. | `/hyperframes-keyframes` روی این صحنه زوم آهسته بذار |
| `hyperframes-creative` | رنگ، تایپوگرافی، طراحی و جهت خلاقانه. | خودکار |
| `hyperframes-registry` | جست‌وجو و نصب حدود ۴۰۰ بلوک آماده: گلیچ، نمودار، کانفتی، ترمینال و… | `/hyperframes-registry` افکت گلیچ داری؟ |
| `hyperframes-studio` | کار مشترک در محیط Studio، استوری‌بورد و چیدمان تایم‌لاین. | خودکار |
| `media-use` | پیدا کردن یا ساختن موزیک، افکت صوتی، تصویر، آیکون، لوگو، گوینده و زیرنویس. | `/media-use` یه افکت صوتی ووش پیدا کن |

## ۵. ساخت ویدیو با Remotion

| `remotion-motion-graphics` | قواعد ساخت موشن حرفه‌ای و غیرتکراری با Remotion. | `/remotion-motion-graphics` یه اینترو با Remotion بساز |
| `remotion-create` | ساخت پروژه یا ویدیوی جدید. | `/remotion-create` |

| `remotion-captions` | زیرنویس و انیمیشن کلمه‌ها. | `/remotion-captions` |
| `remotion-maps` | نقشهٔ متحرک، مسیر و نشانگر. | `/remotion-maps` |
| `remotion-multimedia` | برش و پردازش ویدیو در مرورگر. | خودکار |
| `remotion-interactivity` | ساختار قابل‌ویرایش در Studio. | خودکار |
