# ig-repurpose

یک محتوای بلند خوب چهار تا شش پست در خودش دارد. بیشتر آدم‌ها یکی را درمی‌آورند
و بقیه را دور می‌ریزند.

قبل از نوشتن، `../ig-human/fa-style.md` و `~/.claude/instagram/feedback.md` را بخوان.

هر پستی که از این منبع درمی‌آید **فقط از خود منبع و فایل‌هایی که کاربر داده**
ساخته می‌شود؛ هر بیت با نام فایل و زمان دقیق. صدا یا تصویری که در فایل‌ها نیست
(«صورت خودتان»، «یک ضبط تازه») پیشنهاد نکن. جمله‌ای که لازم است ولی کسی نگفته،
متن روی صفحه می‌شود.

## ورودی

متن پیاده‌شده، مقاله، خبرنامه، اسکریپت، خلاصه‌ی جلسه، لایو. اگر کاربر فایل صوتی
یا ویدیو داد و این جلسه ابزار تبدیل گفتار به متن دارد (مثلاً اسکیل `transcribe`)،
از آن استفاده کن؛ وگرنه بخواه متن را پیست کند. **کل متن را بخوان** قبل از
بیرون کشیدن هر چیزی.

اگر منبع ویدیوی خود کاربر است، فایلش را هم بخواه. ریلزی که روی فیلم خود کاربر
ساخته شده، از ریلزی که همان حرف‌ها را دوباره خوانده بهتر است. برای کارگاه یا
کلاس ضبط‌شده این قوی‌ترین منبع است: سؤال‌های واقعی شاگردها و واکنش‌های واقعی.

## بیرون بکش، خلاصه نکن

خلاصه‌ی یک ویدیو ریلز نیست. کسی خلاصه نمی‌خواهد. منبع را بگرد و چیزهایی را
دربیاور که روی پای خودشان می‌ایستند:

| چه چیزی | چیست |
| --- | --- |
| **ادعا** | هر جمله‌ای که بحث راه می‌اندازد |
| **عدد** | هر رقم، هزینه، مدت، درصد |
| **داستان** | هر لحظه‌ای با یک آدم، یک صحنه و یک هزینه |
| **سازوکار** | هر «این‌طوری کار می‌کنه که...» |
| **اشتباه** | هر اعتراف به چیزی که خراب شد |
| **جمله** | هر جمله‌ای که همین‌طور قابل نقل است |

قبل از نوشتن هر چیزی، آنچه پیدا کردی را با تعداد لیست کن. اگر منبع کمتر از چهار
مورد داد، لاغر است، و چهار پستی که از آن بیرون بکشی هم لاغر می‌شوند. بگو.

برای کارگاه آموزش ابزارهای هوش مصنوعی: هر ابزار معمولاً یک «سازوکار» است و
جمع‌شان یک کاروسل؛ تجربه‌ی واقعی مدرس با یک ابزار یک «داستان» است و ریلز.
قیمت‌ها و رایگان‌بودن‌هایی که در کارگاه گفته شده، تا تاریخ همان کارگاه درست
بوده‌اند؛ تأیید بگیر.

## بعد برای هر تکه قالب انتخاب کن

همه چیز ریلز نیست.

- **ادعا، اشتباه، داستان** ← ریلز. صدا و صورت لازم دارند.
- **سازوکار، لیست شماره‌دار** ← کاروسل. باید دوباره خوانده شوند.
- **یک جمله‌ی قابل نقل** ← یک فریم استوری، نه یک پست.

## بعد هفته را بساز

هر تکه یک پست می‌شود و هر پست کاملاً روی پای خودش می‌ایستد. بیننده منبع را
ندیده و هرگز نخواهد دید. هرگز ننویس «همون‌طور که توی ویدیوی قبلی گفتم». پست
خودش آن چیز است.

برای هر کدام یک فرمول هوک از `ig-reel/hooks.json` بگذار و متنوعشان کن. پنج پست
از یک منبع با یک شکل هوک شبیه کارخانه‌ی محتواست، چون هست.

اگر منبع ویدیوی خود کاربر است، **از فیلم واقعی استفاده کن**. کلیپی که در آن
حرف را زد، با واکنش واقعی‌اش، همیشه از ضبط دوباره بهتر است. روی جمله ببُر، نه
روی نفس.

ترتیب هفته: قوی‌ترین ادعا اول، داستان وسط هفته، سازوکار آخر، وقتی کسانی که
قبلی‌ها را دوست داشتند منتظرش‌اند.

## خروجی

```
منبع: «کارگاه هوش مصنوعی برای معلمان» (۴۲ دقیقه، ۵٬۸۰۰ کلمه)

پیدا شد  ۵ ادعا، ۹ عدد، ۳ داستان، ۶ سازوکار، ۲ اشتباه، ۷ جمله‌ی قابل نقل

هفته
یکشنبه    ریلز     #2  Negative Command  ابزار عوض نکن، پرامپتت رو عوض کن
                                         کلیپ دقیقه‌ی ۱۴:۲۰، آخرش شاگردها می‌خندند
دوشنبه    کاروسل   کپشن کار ب            ۶ ابزار و کار هر کدام  {{قیمت‌ها را تأیید کن}}
چهارشنبه  ریلز     #21 Mid-Sentence      «...و همون موقع اینترنت کلاس قطع شد»
جمعه      ریلز     #5  Time Collapse     طراحی سؤال از دو ساعت به پنج دقیقه

بگو «یکشنبه رو بنویس» تا پیش‌نویسش کنم.
```

بعد به درخواست، یکی‌یکی پیش‌نویس کن، هر کدام از `/ig-reel` و `/ig-human`. چهار
اسکریپت کامل را یکجا تحویل نده. همه شبیه هم می‌شوند و کاربر هیچ‌کدام را ضبط
نمی‌کند.
