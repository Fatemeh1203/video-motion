# ویدیو تبلیغاتی سایت، نسخهٔ «فضای هوشمند»

ویدیوی تبلیغاتی ۱۱۲ ثانیه‌ای (کمتر از ۲ دقیقه)، فارسی و راست‌به‌چپ، ۱۹۲۰×۱۰۸۰ (۱۶:۹)، بر اساس
شکل جدید سایت: تم «THE INTELLIGENCE SPACE»، حلقهٔ چرخان شش دروازه در صفحهٔ اصلی، و یک جهان
سه‌بعدی تعاملی برای هر بخش.

فایل نهایی: `renders/fatemeh-intro-v2.mp4`

## چه چیزی با نسخهٔ اول فرق دارد؟

در نسخهٔ اول، صحنه‌ها با HTML دوباره ساخته شده بودند. در این نسخه، **فیلم واقعی خود سایت**
در ویدیو آمده است:

1. سایت (`project-site-2026`) روی همین سیستم ساخته و اجرا شد: Postgres، `prisma db push`،
   دادهٔ نمونه، شبیه‌سازها و `next build`، دقیقاً مثل workflow دموی GitHub Pages خود ریپو.
2. `scripts/capture-site.cjs` صفحه‌ها را در کروم بی‌سر (با WebGL نرم‌افزاری) باز می‌کند و
   ساعت مرورگر (`performance.now` و `requestAnimationFrame`) را با یک ساعت مجازی عوض می‌کند.
   به این ترتیب هر فریم دقیقاً ۱/۳۰ ثانیه بعد از قبلی است، هرچقدر هم که رندر کند باشد.
   حرکت ماوس هم شبیه‌سازی می‌شود تا جهان‌ها واکنش نشان دهند.
3. در نسخه‌های `*-clean`، همهٔ لایه‌های صفحه به‌جز بوم سه‌بعدی پنهان شده‌اند، چون نمونه‌کارها،
   ایجنت‌ها و فایل‌های دیتابیس نمونه واقعی نیستند.

## اسکیل‌ها
مثل نسخهٔ اول، `/hyperframes` مسیر `/general-video` را انتخاب کرد. `hyperframes-core`
(قرار دادن ویدیو داخل زیرکامپوزیشن و `data-playback-rate`)، `hyperframes-creative`،
`hyperframes-animation`، `media-use` (افکت‌های صوتی) و `hyperframes-cli` (check، snapshot و
render) هم استفاده شدند.

## ساخت دوباره
```bash
# ۱) اجرای سایت روی localhost:3100 (مثل .github/workflows/static-demo.yml در ریپوی سایت)
# ۲) گرفتن فیلم‌ها
node scripts/capture-site.cjs <puppeteer-core> http://localhost:3100 /tmp/clips
cp /tmp/clips/*.mp4 assets/clips/
# ۳) بررسی و رندر
npx hyperframes check
npx hyperframes render -o renders/fatemeh-intro-v2.mp4 --quality delivery
```
