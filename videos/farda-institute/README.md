# ویدیوی معرفی پروژهٔ «آموزشگاه علمی فردا»

ویدیوی ۱۲۰ ثانیه‌ای، فارسی و راست‌به‌چپ، ۱۹۲۰×۱۰۸۰، بدون گوینده (موسیقی + افکت صوتی).
فایل نهایی: `renders/farda-institute.mp4`. منبع محتوا: مخزن
[Fatemeh1203/Farda-Institute](https://github.com/Fatemeh1203/Farda-Institute).

هویت بصری از خود صفحهٔ همکاران آموزشگاه گرفته شده: آسمان آبی روشن، جوهر سرمه‌ای،
لوگوی خوشنویسی «فردا» و فونت وزیرمتن. روایت: یک واریزی واقعی از README مخزن
(سارا محمدی، ۸۰۰٬۰۰۰ تومان، دورهٔ C001، ۷۰٪) از فرم تا گزارش ماه دنبال می‌شود.

## نکته‌ها

- نام «مریم احمدی» و روز و ساعت کلاس‌ها در صحنهٔ ۹ نمونه‌اند؛ بقیهٔ اعداد و نام‌ها از README مخزن فردا آمده‌اند.
- شکل پیام ربات تلگرام و ایمیل گزارش بازسازی گرافیکی از توضیحات README است، نه اسکرین‌شات.
- هیچ آدرس خصوصی (پنل مدیر، وبهوک، دفتر گوگل‌شیت) در ویدیو نیامده.
- متن گویندگی برای اضافه کردن صدا در آینده: `SCRIPT.md`.

## ساخت دوباره

```bash
python3 scripts/build-index.py                 # index.html: صحنه‌ها، موسیقی و افکت‌ها
python3 scripts/inject-fonts.py compositions/*.html
npx hyperframes check
npx hyperframes render -o renders/raw.mp4 --quality delivery
```
