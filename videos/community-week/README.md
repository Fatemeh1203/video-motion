# یک هفته در کامیونیتی (ریلز ۹:۱۶، ۵۶ ثانیه)

انیمیشن معرفی کامیونیتی هوش مصنوعی با صدای فرید (رایگان، edge-tts). متن گوینده: `SCRIPT.md`.

- خروجی: `renders/community-week.mp4`
- ساختار: یک فایل `index.html`؛ نوار هفت روز هفته بالای تصویر می‌ماند و هر روز یک کارت دارد.
- بررسی: `npm run check` و `npx hyperframes snapshot --at 9.5,18.5,31`

## صدا و موزیک

`python3 scripts/build_voice.py fa-IR-FaridNeural +20%` صدا، موزیکِ پایین‌آمده زیر صدا، افکت‌ها و زمان صحنه‌ها را از نو می‌سازد.
