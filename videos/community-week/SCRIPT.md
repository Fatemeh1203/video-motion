# متن گویندگی «یک هفته در کامیونیتی»

صدا: دلارا (`fa-IR-DilaraNeural`، رایگان با edge-tts)، سرعت ۵٪ آهسته‌تر. زمان هر خط لحظه‌ای
است که گوینده شروع می‌کند. کسرهٔ اضافه (ـِ) فقط برای این گذاشته شده که صدای ماشینی درست
بخواندش. برای تغییر یک خط: متنش را در `voice/lines.txt` عوض کن و دستورهای پایین را دوباره اجرا کن.

| زمان | صحنه | متن |
|---|---|---|
| ۰:۰۰٫۶ | سؤال | اگه فقط یه هفته توی کامیونیتیِ هوش مصنوعی باشی، چی یاد می‌گیری؟ |
| ۰:۰۵٫۸ | شنبه، درس | شنبه، اولین درس. یه ابزارِ هوش مصنوعی رو قدم‌به‌قدم و کاربردی یاد می‌گیری. |
| ۰:۱۳٫۰ | یکشنبه، خبر | یکشنبه، یه درسِ تازه، و خلاصه‌ی خبرهای هوش مصنوعی. خبرها، روزهای فرد میان. |
| ۰:۲۰٫۴ | دوشنبه، جزوه | دوشنبه، می‌بینی هر درس یه جزوه داره؛ هر وقت خواستی، برمی‌گردی و مرورش می‌کنی. |
| ۰:۲۶٫۳ | سه‌شنبه، درس ۹ | سه‌شنبه، مثلاً عکسِ یه فاکتورِ خرید رو می‌دی، و تحلیلِ فروشت رو می‌گیری. |
| ۰:۳۲٫۶ | چهارشنبه، شبیه‌ساز | چهارشنبه، نوبتِ شبیه‌سازهای آموزشیه: ریاضی، فیزیک، برنامه‌نویسی. رایگان، و فقط برای اعضا. |
| ۰:۴۱٫۰ | پنجشنبه، پرسش و پاسخ | پنجشنبه، یه جا گیر می‌کنی. می‌پرسی، و جواب می‌گیری. فاطمه شمس، شبانه‌روز کنارته. |
| ۰:۴۹٫۴ | جمعه | جمعه، دیگه از ابزارهای جدید نمی‌ترسی. می‌دونی از کجا شروع کنی. |
| ۰:۵۵٫۷ | دعوت | کامیونیتیِ هوش مصنوعی، جای کساییه که می‌خوان متحول بشن. لینکِ گروه، همین‌جاست. |

## ساختن دوبارهٔ صدا

```bash
python3 scripts/tts_edge.py fa-IR-DilaraNeural -5% "<متن>" voice/l03.mp3 </dev/null
ffmpeg -nostdin -y -i voice/l03.mp3 -af "silenceremove=start_periods=1:start_threshold=-45dB,areverse,silenceremove=start_periods=1:start_threshold=-45dB,areverse" -ac 1 -ar 24000 voice/l03.wav
python3 scripts/mix_narration.py voice/lines.tsv voice assets/audio/narration.wav 66
```

بعد narration.wav را به mp3 تبدیل کن و موزیک را دوباره زیر صدا پایین بیاور (دستور ffmpeg
در README).
