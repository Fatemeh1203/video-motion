# متن گویندگی «یک هفته در کامیونیتی»

صدا: فرید (`fa-IR-FaridNeural`، صدای آقا، رایگان با edge-tts)، سرعت ۲۰٪ تندتر. اسم با اِعراب «فاطِمه شَمس» نوشته شده (شکل شمارهٔ ۲ که فاطمه انتخاب کرد). زمان هر خط لحظه‌ای
است که گوینده شروع می‌کند. کسرهٔ اضافه (ـِ) فقط برای این گذاشته شده که صدای ماشینی درست
بخواندش. برای تغییر یک خط: متنش را در `voice/lines.txt` عوض کن و دستورهای پایین را دوباره اجرا کن.

| زمان | صحنه | متن |
|---|---|---|
| ۰:۰۰٫۶ | سؤال | اگه فقط یه هفته توی کامیونیتیِ هوش مصنوعی باشی، چی یاد می‌گیری؟ |
| ۰:۰۵٫۰ | شنبه، درس | شنبه، اولین درس. یه ابزارِ هوش مصنوعی رو قدم‌به‌قدم و کاربردی یاد می‌گیری. |
| ۰:۱۱٫۱ | یکشنبه، خبر | یکشنبه، یه درسِ تازه، و خلاصه‌ی خبرهای هوش مصنوعی. خبرها، روزهای فرد میان. |
| ۰:۱۷٫۶ | دوشنبه، جزوه | دوشنبه، می‌بینی هر درس یه جزوه داره؛ هر وقت خواستی، برمی‌گردی و مرورش می‌کنی. |
| ۰:۲۲٫۶ | سه‌شنبه، درس ۹ | سه‌شنبه، مثلاً عکسِ یه فاکتورِ خرید رو می‌دی، و تحلیلِ فروشت رو می‌گیری. |
| ۰:۲۷٫۷ | چهارشنبه، شبیه‌ساز | چهارشنبه، نوبتِ شبیه‌سازهای آموزشیه: ریاضی، فیزیک، برنامه‌نویسی. رایگان، و فقط برای اعضا. |
| ۰:۳۵٫۲ | پنجشنبه، پرسش و پاسخ | پنجشنبه، یه جا گیر می‌کنی. می‌پرسی، و جواب می‌گیری. فاطِمه شَمس، شبانه‌روز کنارته. |
| ۰:۴۲٫۲ | جمعه | جمعه، دیگه از ابزارهای جدید نمی‌ترسی. می‌دونی از کجا شروع کنی. |
| ۰:۴۷٫۳ | دعوت | کامیونیتیِ هوش مصنوعی، جای کساییه که می‌خوان متحول بشن. لینکِ گروه، همین‌جاست. |

## ساختن دوبارهٔ صدا

متن را در `voice/lines.txt` عوض کن (۹ خط: شروع، شنبه تا جمعه، دعوت)، بعد:

```bash
python3 scripts/build_voice.py fa-IR-FaridNeural +20%
```

این دستور صدا را می‌سازد، طول هر خط را اندازه می‌گیرد و زمان صحنه‌ها، موزیک و افکت‌ها را در
`index.html` با آن هماهنگ می‌کند. برای صدای خانم: `fa-IR-DilaraNeural`.
