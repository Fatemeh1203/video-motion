# ریلز «حسابداری آموزشگاه فردا»

ریلز ۳۴ ثانیه‌ای اینستاگرام، ۱۰۸۰×۱۹۲۰، فارسی، بدون گوینده (متن روی صفحه + موسیقی + افکت).
فایل نهایی: `renders/farda-reel.mp4`. همهٔ متن‌ها داخل محدودهٔ امن (x ۱۰۰ تا ۸۶۰، y ۲۵۰ تا ۱۴۲۰).

هوک: فرمول #۱۴ The Callout، امتیاز ۸۱.۴ (STRONG) با `ig-reel/hookscore.py`.

| زمان | کارت روی صفحه | تصویر |
|---|---|---|
| ۰:۰۰ | حقوق مدرس، هنوز با ماشین‌حساب؟ | فیش و فاکتور و اکسل پراکنده، ماشین‌حساب در حال جمع زدن |
| ۰:۰۳ | فیش توی تلگرام، فاکتور توی گالری | کارت‌ها می‌لرزند |
| ۰:۰۶ | آموزشگاه فردا رو ببین | لوگوی فردا |
| ۰:۰۸ | همکار: فقط یه فرم | فرم ثبت واریزی روی گوشی پر می‌شود |
| ۰:۱۱ | شهریه‌ی سارا: ۸۰۰٬۰۰۰ تومان | ارسال ← «در انتظار تأیید مدیر» |
| ۰:۱۴ | میاد تلگرام مدیر | پیام ربات حسابداری |
| ۰:۱۶ | تا تأیید نکنم، ثبت نمی‌شه | برگهٔ تأیید ← «ثبت کن» ← ✅ |
| ۰:۱۹ | سهم مدرس ۷۰٪ = ۵۶۰٬۰۰۰ | تقسیم ۷۰/۳۰ و قفل |
| ۰:۲۲ | قفل، توی ۱۷ شیت فارسی | ردیف تازه در دفتر گوگل‌شیت |
| ۰:۲۵ | آخر ماه: فقط یه دکمه | پنل مدیر «بستن حقوق ماه» |
| ۰:۲۸ | گزارش حقوق + اکسل، توی ایمیل | ایمیل گزارش، «واریز شد» |
| ۰:۳۱ | ماشین‌حساب رو بذار کنار | ماشین‌حساب خط می‌خورد، «سیوش کن»، امضا |

نمونه‌داده‌ها (سارا محمدی، C001، M001، ۷۰٪) از README مخزن Farda-Institute است.

## ساخت دوباره

```bash
python3 scripts/inject-fonts.py index.html   # فقط اگر نشانگر /*FONTS*/ برگشت
npx hyperframes check
npx hyperframes render -o renders/raw.mp4 --quality delivery
```
