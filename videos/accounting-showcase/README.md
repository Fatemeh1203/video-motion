# accounting-showcase

ویدیوی موشن معرفی سیستم حسابداری خودکار آموزشگاه علمی فردا، برای تاپیک «نتایج» کامیونیتی.
۴۰ ثانیه، ۱۹۲۰×۱۰۸۰، فارسی و راست‌چین، بدون گوینده (موسیقی + افکت صوتی).

تم «دفترچهٔ مدرسه»: زمینهٔ کاغذی کرم با خط‌های آبی دفتر و خط حاشیهٔ قرمز، جوهر سرمه‌ای،
رنگ‌های آبی، سبز، کهربایی و بنفش. موسیقی شاد و سبک (ماریمبا، پیانو، شیکر، ۱۱۲ BPM) از
`scripts/make-school-music.py`.

| صحنه | زمان | محتوا |
|---|---|---|
| s1-hook | ۰ تا ۶٫۱ | کارهای دستی آخر ماه دور تیتر جمع می‌شوند: «حسابداری دستی آموزشگاه» |
| s2-title | ۵٫۸ تا ۱۱٫۹ | «حسابداری خودکار آموزشگاه» + آمار: ۹ ورک‌فلو، ۱۷ شیت، ۰ خطا در ۴۰٬۰۰۰ روز تقویم شمسی |
| s3-flow | ۱۱٫۶ تا ۲۱٫۲ | فرم واریزی ← تأیید مدیر در تلگرام ← ردیف تازه در شیت «درآمد» |
| s4-share | ۲۰٫۸ تا ۲۷٫۸ | ۸۰۰٬۰۰۰ تومان ← سهم مدرس ۷۰٪ (۵۶۰٬۰۰۰) و آموزشگاه ۳۰٪ (۲۴۰٬۰۰۰) |
| s5-reports | ۲۷٫۵ تا ۳۴٫۹ | ماهانه، فصلی، شش‌ماهه، سالانه + ایمیل با پیوست اکسل + تعدیل آورده با طلا/دلار/تورم |
| s6-outro | ۳۴٫۵ تا ۴۰ | «فاطمه شمس» + «آموزشگاه فردا» |

صحنه‌های ۱ تا ۵ با سرعت ۱٫۱۴ برابر پخش می‌شوند (`tl.timeScale` داخل هر صحنه)؛ زمان‌های داخل کد همان نسخهٔ ۴۷ ثانیه‌ای است.

همهٔ اعداد از مخزن `Fatemeh1203/Farda-Institute` آمده‌اند. مبالغ و شناسه‌های C001 و M001
همان نمونهٔ تست README آن مخزن‌اند، نه دادهٔ واقعی هنرجو یا مدرس.

## ساخت دوباره

```bash
python3 scripts/make-school-music.py assets/audio/bgm.wav 40   # سپس با ffmpeg به bgm.mp3
python3 scripts/inject-fonts.py compositions/*.html   # فقط اگر مارکر /*FONTS*/ برگشت
npm run check
npx --yes hyperframes@0.8.80 render --quality delivery -o renders/raw.mp4
```

خروجی مخزن: `renders/accounting-showcase.mp4` (crf 19).
