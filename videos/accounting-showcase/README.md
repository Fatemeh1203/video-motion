# accounting-showcase

ویدیوی موشن معرفی سیستم حسابداری خودکار آموزشگاه علمی فردا، برای تاپیک «نتایج» کامیونیتی.
۶۰ ثانیه، ۱۹۲۰×۱۰۸۰، فارسی و راست‌چین، بدون گوینده (موسیقی + افکت صوتی).

تم «دفترچهٔ مدرسه»: زمینهٔ کاغذی کرم با خط‌های آبی دفتر و خط حاشیهٔ قرمز، جوهر سرمه‌ای،
رنگ‌های آبی، سبز، کهربایی و بنفش. موسیقی شاد و سبک (ماریمبا، پیانو، شیکر، ۱۱۲ BPM) از
`scripts/make-school-music.py`.

| صحنه | شروع | محتوا |
|---|---|---|
| s1-hook | ۰ | «آموزشگاه ما یک حسابدار تازه دارد»… اسمش n8n (۱٫۲ برابر) |
| s2-overview | ۴٫۲ | کل سیستم: همکاران و مدیر ← n8n (۹ ورک‌فلو) ← گوگل‌شیت ← تلگرام، ایمیل، درایو |
| s3-staff | ۱۰ | بخش ۱: سه فرم همکاران + گوشی با صفحهٔ واقعی همکاران |
| s3-flow | ۱۵ | فرم ۱ واریزی: فرم ← تأیید تلگرام ← شیت درآمد (۱٫۵ برابر) |
| s4-share | ۲۱٫۹ | سهم مدرس ۷۰/۳۰ + اولویت درصد (۱٫۶ برابر) |
| s5-expense | ۲۶٫۵ | فرم ۲ هزینه: دسته، فاکتور به گوگل‌درایو، شیت هزینه‌ها |
| s6-classes | ۳۱٫۳ | فرم ۳: برنامهٔ هفتگی، گروه‌بندی خودکار، جبرانی، حذف نرم |
| s7-admin | ۳۶٫۹ | بخش ۲: پنل مدیر (صفحهٔ قفل) + ۸ ابزار مدیر |
| s8-payroll | ۴۱٫۹ | بستن ماه: فرمول حقوق، حقوق مدرسین، گزارش ماهانه، ایمیل + اکسل |
| s9-capital | ۴۷٫۱ | آورده درآمد نیست؛ ارزش طلایی/دلاری/تورمی + گزارش‌های دوره‌ای |
| s10-trust | ۵۲٫۳ | ساخته‌شده برای اعتماد: شش ضمانت سیستم |
| s6-outro | ۵۶٫۵ | «فاطمه شمس» + «آموزشگاه فردا» |

عکس‌های `assets/img/` از `index.html` و `panel/index.html` مخزن Farda-Institute گرفته شده‌اند
(Playwright، سرور محلی). پنل مدیر فقط در حالت قفل نشان داده می‌شود؛ لینک‌های رمزگذاری‌شده‌اش هرگز.

همهٔ اعداد از مخزن `Fatemeh1203/Farda-Institute` آمده‌اند. مبالغ و شناسه‌های C001 و M001
همان نمونهٔ تست README آن مخزن‌اند، نه دادهٔ واقعی هنرجو یا مدرس.

## ساخت دوباره

```bash
python3 scripts/make-school-music.py assets/audio/bgm.wav 60.32   # سپس با ffmpeg به bgm.mp3
python3 scripts/inject-fonts.py compositions/*.html   # فقط اگر مارکر /*FONTS*/ برگشت
npm run check
npx --yes hyperframes@0.8.80 render --quality delivery -o renders/raw.mp4
```

خروجی مخزن: `renders/accounting-showcase.mp4` (crf 19).
