# accounting-showcase

ویدیوی موشن معرفی سیستم حسابداری خودکار آموزشگاه علمی فردا، برای تاپیک «نتایج» کامیونیتی.
۴۷ ثانیه، ۱۹۲۰×۱۰۸۰، فارسی و راست‌چین، بدون گوینده (موسیقی + افکت صوتی).

| صحنه | زمان | محتوا |
|---|---|---|
| s1-hook | ۰ تا ۷ | کارهای دستی آخر ماه دور تیتر جمع می‌شوند: «حسابداری دستی آموزشگاه» |
| s2-title | ۶٫۶ تا ۱۳٫۶ | «حسابداری خودکار آموزشگاه» + آمار: ۹ ورک‌فلو، ۱۷ شیت، ۰ خطا در ۴۰٬۰۰۰ روز تقویم شمسی |
| s3-flow | ۱۳٫۲ تا ۲۴٫۲ | فرم واریزی ← تأیید مدیر در تلگرام ← ردیف تازه در شیت «درآمد» |
| s4-share | ۲۳٫۸ تا ۳۱٫۸ | ۸۰۰٬۰۰۰ تومان ← سهم مدرس ۷۰٪ (۵۶۰٬۰۰۰) و آموزشگاه ۳۰٪ (۲۴۰٬۰۰۰) |
| s5-reports | ۳۱٫۴ تا ۳۹٫۹ | ماهانه، فصلی، شش‌ماهه، سالانه + ایمیل با پیوست اکسل + تعدیل آورده با طلا/دلار/تورم |
| s6-outro | ۳۹٫۵ تا ۴۷ | «هر ورودی فقط یک بار. بقیه‌اش خودکار.» + n8n، Google Sheets، Telegram، Gmail + فاطمه شمس |

همهٔ اعداد از مخزن `Fatemeh1203/Farda-Institute` آمده‌اند. مبالغ و شناسه‌های C001 و M001
همان نمونهٔ تست README آن مخزن‌اند، نه دادهٔ واقعی هنرجو یا مدرس.

## ساخت دوباره

```bash
python3 scripts/make-bgm.py assets/audio/bgm.wav 47   # سپس با ffmpeg به bgm.mp3
python3 scripts/inject-fonts.py compositions/*.html   # فقط اگر مارکر /*FONTS*/ برگشت
npm run check
npx --yes hyperframes@0.8.80 render --quality delivery -o renders/raw.mp4
```

خروجی مخزن: `renders/accounting-showcase.mp4` (crf 19).
