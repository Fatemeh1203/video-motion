# ویدیو موشن تبلیغاتی آموزشگاه علمی فردا

ویدیوی تبلیغاتی **۲ دقیقه‌ای (۱۲۰ ثانیه)**، فارسی و راست‌به‌چپ، ۱۹۲۰×۱۰۸۰ (۱۶:۹) برای
[aifardainstitute.ir](https://aifardainstitute.ir/).
فایل نهایی: `renders/farda-promo.mp4`

## هویت بصری
- **لوگوی خوشنویسی «فردا»** از مخزن `Fatemeh1203/Farda-Institute` (رنگ‌آمیزی سرمه‌ای روی پس‌زمینهٔ شفاف).
- **رنگ‌ها** همان رنگ‌های صفحهٔ آموزشگاه: آسمان آبی روشن (`#bcd8fb` تا `#f6faff`)، سرمه‌ای
  (`#243a63`) و آبی لینک (`#3d6fd6`)، به‌همراه ابرهای شناور مثل خود صفحه. برای ریتم، صحنه‌های
  شب‌آبی و طلایی آفتاب هم اضافه شده است.
- **فونت Vazirmatn** و شعار «از امروز به فردا بیایید».

## صدا
- **موسیقی** با `scripts/make-bgm.py` به‌صورت کد ساخته شده (۱۰۴ BPM، شاد و روشن) و مشکل کپی‌رایت ندارد.
- **افکت‌ها** (whoosh، pop، ضربه، تایپ، chime) هم‌زمان با تغییر صحنه‌ها.

## ساخت دوباره و ویرایش
```bash
cd videos/farda-promo
npx hyperframes preview      # پیش‌نمایش و ویرایش در Studio
npx hyperframes check        # بررسی
npx hyperframes render -o renders/farda-promo.mp4 --quality delivery
```
متن هر صحنه در `compositions/s1-hook.html` تا `s8-cta.html` است.
